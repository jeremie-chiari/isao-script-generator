# Retention & Performance Benchmarks

## 30-Second Retention (Intro Drop)

| % at 0:30 | Algorithm Verdict | Action |
|---|---|---|
| < 50% | Fail | Rewrite intro completely using P.P.P. |
| 50-60% | Passable | Improve Preuve section, add stronger Péril |
| 60-70% | Good/Solid | Standard target. Optimize for 70%+ |
| 70%+ | Excellent | Viral signal. YouTube shows to non-subscribers |

## Average View Duration by Video Length

| Video Duration | "Correct" Retention | "Excellent" (Viral) |
|---|---|---|
| 5 min | 50% (2:30) | 70%+ (3:30) |
| 10-15 min | 35-45% (4-6 min) | 50%+ (7 min+) |
| 20 min+ | 25-35% (6-8 min) | 40%+ (10 min+) |

## Subscriber Conversion Rate

| Performance | Ratio Subs/Views | Example |
|---|---|---|
| Average | 0.5% | 1000 views → 5 subs |
| Good | 1% | 1000 views → 10 subs |
| Excellent | 2-5% | 1000 views → 20-50 subs |

## End-of-Video Survival Rate

| % at last second | Score | Meaning |
|---|---|---|
| < 10% | Weak | Too long, repetitive, or ending adds no value |
| 15-20% | Correct | YouTube average for long format |
| 25-35% | Very Good | Loyal audience. Algorithm loves this |
| 45%+ | Elite | Master storytelling (MrBeast level) |
