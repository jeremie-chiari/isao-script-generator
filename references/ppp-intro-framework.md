# P.P.P. Intro Framework (0-30 seconds)

The P.P.P. framework is the mandatory structure for every video intro. Each element has a strict timing window.

## Preuve (0-5s) — Show the Result

**Shot**: `[ÉCRAN]` — Full screen showing the final product/result
**Voice**: Describe what's on screen in one punchy sentence.
**Purpose**: Instant credibility. The viewer sees what they'll achieve.

**Examples**:
- "Regardez cette application de gestion de stock, je l'ai codée en 4 minutes avec Claude."
- "Voilà le dashboard en temps réel qu'on va construire ensemble."
- "Ce site e-commerce est en ligne, et il m'a coûté 0€."

**Rules**:
- NO talking head. Show the product.
- NO greetings. First word = description of what's on screen.
- NO logos, no animated intros, no music intros.

## Promesse (5-15s) — State the Learning

**Shot**: `[FACE CAM]` — Close-up, direct eye contact
**Voice**: State exactly what the viewer will learn + announce step count.
**Purpose**: Set expectations. Create a mental framework.

**Examples**:
- "Dans 10 minutes, en 5 étapes, vous saurez faire exactement la même chose."
- "Aujourd'hui, 4 étapes pour passer de zéro à une app en production."
- "Je vous montre les 3 étapes pour automatiser ça avec Claude Code."

**Rules**:
- Always include the number of steps.
- Always include a timeframe ("in X minutes").
- Tease the star step: "L'étape 3 est celle qui change tout."

## Péril / Curiosité (15-30s) — Create Tension

**Shot**: `[FACE CAM]` or `[ÉCRAN]` showing the danger
**Voice**: Warning, common mistake, or curiosity hook.
**Purpose**: Create an open loop that won't close until the star step.

**Examples**:
- "Mais attention, si vous ne réglez pas ce paramètre précis, Claude va halluciner et casser votre code."
- "Le plus impressionnant, c'est ce que Claude fait à l'étape 3 pour corriger les bugs tout seul."
- "90% des gens ratent cette étape et leur déploiement plante."

**Rules**:
- Must create an unresolved question/tension.
- The resolution must come in the star step (middle of video), not immediately.
- Use fear ("si vous ne faites pas ça...") or curiosity ("le plus fou c'est...").
