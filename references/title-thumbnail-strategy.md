# Title & Thumbnail Strategy

## Thumbnail: The 3-Element Rule

A thumbnail must contain EXACTLY 3 informational elements, no more:

1. **A recognizable logo** (e.g., Claude, GPT, Vercel)
2. **A number or metric** (e.g., "20 MIN", "0€", "5 ÉTAPES")
3. **An object of desire** (e.g., a running app, a "Deploy" button, a dashboard)

**Why 3?** More elements create visual noise. The thumbnail must be readable at phone size (the primary discovery surface).

## Title: The Transformation Formula

### Bad Titles (Descriptive)
- "Tuto Claude Code"
- "Comment utiliser les skills Claude"
- "Présentation de Claude Projects"

### Good Titles (Transformation-Oriented)
- "J'ai codé [NOM DE L'APP] en 10 min avec Claude (Étape par étape)"
- "De 0 à une app en ligne : 20 minutes avec Claude Code"
- "Je scrape LinkedIn, Indeed et Malt sans écrire une ligne de code"

### Title Structure Patterns

| Pattern | Template | Example |
|---|---|---|
| Result + Time | "J'ai [RÉSULTAT] en [TEMPS] avec [OUTIL]" | "J'ai codé un SaaS en 10 min avec Claude" |
| Zero to Hero | "De [POINT A] à [POINT B] : [TEMPS/MÉTHODE]" | "De 0 à une app en ligne : 20 minutes" |
| Challenge | "[ACTION AUDACIEUSE] sans [CONTRAINTE]" | "Je scrape 3 sites sans coder" |
| Guide | "[NOMBRE] étapes pour [OBJECTIF] avec [OUTIL]" | "5 étapes pour déployer avec Claude Code" |
| Curiosity | "Ce que [OUTIL] fait quand [SITUATION SURPRENANTE]" | "Ce que Claude fait quand votre code plante" |

## CTR Benchmarks

| CTR | Rating | Action |
|---|---|---|
| < 3% | Poor | Rethink title AND thumbnail completely |
| 3-4% | Below average | Test new thumbnail variants |
| 4-5% | Average | Optimize title wording |
| 5-6% | Good | On target |
| 6%+ | Excellent | Current target |

## A/B Testing Notes
- Always A/B test thumbnails with different visual approaches
- Test title variations with small wording changes
- The combination of title + thumbnail must tell a coherent story
- Title and thumbnail should complement each other, not repeat the same information
