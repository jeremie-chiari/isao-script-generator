## Thumbnails (3 concepts -- regle des 3 elements)

### Concept 1 -- "Le jeu + le chrono"
| Element | Contenu |
|---|---|
| Logo reconnaissable | Logo Claude (icone anthracite/orange) en bas a gauche |
| Nombre/metrique | "15 MIN" en gros, police bold, couleur cyan #00B2C2, en haut a gauche |
| Objet de desir | Screenshot du jeu Sky Raptors en pleine action -- explosions, avion cyan, ennemis rouges, HUD visible |
| Style | Fond noir. Le jeu occupe les 2/3 droits. "15 MIN" est tres grand et lisible sur mobile. Logo Claude discret mais reconnaissable. Palette ISAO : cyan/anthracite/blanc. |

### Concept 2 -- "Terminal vers jeu"
| Element | Contenu |
|---|---|
| Logo reconnaissable | Terminal Claude Code (fond sombre, texte clair, barre de commande visible) |
| Nombre/metrique | "10 PROMPTS" en jaune #FFE566 au centre |
| Objet de desir | Split screen vertical : terminal Claude Code a gauche (prompt visible) / jeu Sky Raptors a droite (gameplay colore) |
| Style | Contraste fort entre le terminal sombre et le jeu colore. Fleche cyan #00B2C2 du terminal vers le jeu. Lisible sur mobile grace au split net et au texte central. |

### Concept 3 -- "Avant / Apres"
| Element | Contenu |
|---|---|
| Logo reconnaissable | Logo Claude en coin superieur droit |
| Nombre/metrique | "0 CODE" en blanc bold sur fond anthracite #2D2D2D, en haut a gauche |
| Objet de desir | Transformation : canvas vide noir a gauche (avec juste le titre "SKY RAPTORS" en petit) vers jeu complet a droite (boss, explosions, HUD, power-ups) |
| Style | Split horizontal avec fleche cyan au centre. Cote gauche desature/gris, cote droit sature/vibrant. Le contraste raconte l'histoire sans lire le titre. |

**Recommandation** : Concept 1 -- le plus lisible sur mobile. Le jeu en action attire l'oeil instantanement. "15 MIN" cree l'envie et le logo Claude identifie l'outil. Concept 2 en test A/B.

## Strategie de publication

- **Jour** : Mardi ou jeudi, 14h-16h (pic audience tech francophone)
- **Short associe** : Publier le short 24-48h AVANT la video longue pour generer de l'anticipation
- **Commentaire sur le short** : "Tuto complet avec la methode et tous les prompts demain a 15h"
- **Post Skool** : Partager dans la communaute avec les prompts en bonus exclusif
- **Cross-promo** : Ajouter en end screen de la video d'installation de Claude Code
