# Checklist Montage -- Sky Raptors : Showcase + Reveal avec Claude Code

**Format** : Showcase (le jeu est DEJA construit). On montre le resultat, puis on revele la methode.

---

## 1. Pre-tournage

### Captures du jeu (a faire AVANT le tournage)
- [ ] Gameplay complet enregistre en 1080p 60fps (3-5 min de jeu fluide)
- [ ] Capture du jeu au demarrage : ecran titre "SKY RAPTORS"
- [ ] Capture gameplay basique : avion + tir + deplacement
- [ ] Capture des ennemis en mouvement sinusoidal
- [ ] Capture d'une explosion de particules (ralenti si possible)
- [ ] Capture du fond etoile parallax (bien visible)
- [ ] Capture du HUD complet (score, niveau, vies mini-avions, barre progression)
- [ ] Capture d'un power-up qui tombe + activation (shield / double / triple tir)
- [ ] Capture de l'arrivee du boss (descente + barre de vie)
- [ ] Capture du boss phase 2 (accelere + tirs plus rapides)
- [ ] Capture du game over (overlay + score final + highscore)
- [ ] Capture d'un level up (transition de niveau)

### Captures du CLAUDE.md
- [ ] Screencast du fichier CLAUDE.md ouvert dans un editeur (VS Code ou terminal)
- [ ] Capture de la section "Architecture" du CLAUDE.md
- [ ] Capture de la section "Regles de code" du CLAUDE.md
- [ ] Capture de la section "Constantes" du CLAUDE.md
- [ ] Capture de la section "Checklist" du CLAUDE.md

### Captures des prompts
- [ ] Screenshot de chaque prompt (10 prompts) dans le terminal Claude Code
- [ ] Pour les prompts 1, 2, 5, 6 : capture du resultat AVANT et APRES le prompt
- [ ] Pour les prompts 7, 8, 9 : captures split screen avant/apres (fond noir vs etoiles, sans HUD vs avec HUD, sans boss vs avec boss)

### Preparation technique
- [ ] Face cam ON et testee (cadrage, eclairage, mise au point)
- [ ] Micro verifie (son clair, pas de souffle)
- [ ] Ecran propre (pas de notifications, pas d'onglets perso)
- [ ] Resolution ecran 1920x1080
- [ ] Skool ISAO ouvert dans un onglet (pour le bridge communaute)
- [ ] Document avec les 10 prompts prets a montrer a l'ecran

---

## 2. Tournage

### Face cam -- Passages a enregistrer
- [ ] Intro P.P.P. : Promesse (5-15s) + Peril (15-30s) -- PAS de greeting
- [ ] Transition apres la demo : "le vrai sujet : comment j'ai fait"
- [ ] Explication du CLAUDE.md : "Le secret, c'est ce fichier"
- [ ] Analogie du collegue : "C'est comme briefer un collegue"
- [ ] Introduction des prompts : "10 prompts au total, je vais vous montrer les plus importants"
- [ ] Reaction aux explosions de particules (delayed reveal)
- [ ] CTA engagement (~1:30) : question + like + abo
- [ ] Transition prompt : "10 prompts comme ca, en francais, copies-colles"
- [ ] Introduction du polish : "Regardez la difference..."
- [ ] Reaction au polish avant/apres
- [ ] Recap : "Un CLAUDE.md + 10 prompts + 15 minutes = un jeu complet"
- [ ] Bonus : le prompt de debug
- [ ] Bridge communaute : 4 phases (transition, visite Skool, pourquoi + prix, CTA)

### Ecrans a enregistrer
- [ ] Gameplay live du jeu (demo etape 1) -- jouer VRAIMENT, pas de capture statique
- [ ] Scroll lent du fichier CLAUDE.md (etape 2)
- [ ] Zooms sur les sections cles du CLAUDE.md
- [ ] Affichage des prompts 1, 2, 5, 6 a l'ecran (etape 3)
- [ ] Split screen avant/apres pour les prompts 7, 8, 9 (etape 4)
- [ ] Navigation Skool en direct pour le bridge communaute

---

## 3. Montage

### Intro P.P.P. (0:00-0:30) -- CRITIQUE
- [ ] Premier frame = le jeu Sky Raptors en action (PAS de talking head, PAS de logo)
- [ ] Premier mot = description de ce qu'on voit ("Ca, c'est Sky Raptors")
- [ ] Pas de "Bonjour", "Salut", ou greeting
- [ ] Gameplay intense visible : tirs, ennemis, explosions, boss, HUD
- [ ] Nombre d'etapes annonce (5)
- [ ] Star step teasee ("l'etape 3 c'est la plus interessante")
- [ ] Tension creee (sans CLAUDE.md -> code desorganise)
- [ ] Mention des chapitres
- [ ] Promesse du bonus en fin de video (les prompts en description)

### Etape 1 -- La demo (0:30-2:30)
- [ ] Gameplay en plein ecran -- le viewer voit un VRAI jeu
- [ ] Features pointees une par une avec overlays texte ou fleches
- [ ] Zooms sur : explosions particules, HUD, power-up, boss
- [ ] Retour face cam : "Tout ca, c'est 10 prompts"
- [ ] CTA engagement a ~1:30
- [ ] Tease transition vers etape 2

### Etape 2 -- Le CLAUDE.md (2:30-4:30)
- [ ] Face cam pour introduire le concept
- [ ] Screencast du CLAUDE.md avec scroll lent
- [ ] Zooms sur les 4 sections cles (architecture, regles, constantes, checklist)
- [ ] Face cam pour l'analogie du collegue
- [ ] Tease transition vers etape 3

### Etape 3 -- Les prompts / Star step (4:30-7:30)
- [ ] Format prompt -> resultat pour chaque prompt montre
- [ ] Prompt 1 : structure -> canvas avec "SKY RAPTORS" en cyan
- [ ] Prompt 2 : avion -> avion cyan avec flammes animees
- [ ] Prompt 5 : ennemis -> ennemis rouges en sinusoide
- [ ] Prompt 6 : collisions -> DELAYED REVEAL avant les explosions
- [ ] Face cam reaction sur les explosions
- [ ] Tease transition vers etape 4

### Etape 4 -- Le polish (7:30-9:30)
- [ ] Split screen avant/apres pour le fond etoile (noir plat vs parallax)
- [ ] Split screen avant/apres pour le HUD (rien vs HUD complet)
- [ ] Gameplay du boss (arrivee, barre de vie, phase 2, power-ups)
- [ ] Face cam : "3 prompts. La difference entre prototype et jeu fini."
- [ ] Tease transition vers etape 5 + bonus

### Etape 5 -- Votre tour (9:30-11:00)
- [ ] Recap visuel rapide (value stack : 10 checks)
- [ ] Face cam : "Le guide avec les 10 prompts, c'est en description"
- [ ] Rythme de montage ACCELERE sur les 60 dernieres secondes
- [ ] REVEAL FINAL : jeu complet en plein ecran
- [ ] BONUS : prompt de debug (les 30 dernieres secondes)
- [ ] Promesse tenue : "Comme promis, les prompts sont en description"

### Bridge communaute ISAO (11:00-14:00)
- [ ] Phase 1 : Transition naturelle, meme ton que le contenu
- [ ] Phase 2 : Screencast REEL de Skool (feed, classroom, calendrier, post recent)
- [ ] Phase 3 : Stats (5-7% solo vs 65% accompagne), prix (9 euros/mois, annulable)
- [ ] Phase 4 : CTA + end screen
- [ ] Pas de "places limitees" ni urgence artificielle
- [ ] Pas de "moins qu'un cafe"
- [ ] Pas de culpabilisation
- [ ] Prix dit UNE FOIS clairement
- [ ] Alternative gratuite mentionnee (YouTube)
- [ ] End screen apparait 5-10s AVANT la fin
- [ ] Teaser video suivante : "Comment installer Claude Code"

### Transitions et rythme
- [ ] Compteur d'etapes visible ("1/5", "2/5"...) a chaque changement d'etape
- [ ] Value stack cumulatif apres chaque etape
- [ ] Changement de plan toutes les 30s
- [ ] Element graphique toutes les 45s (texte anime, fleche, highlight)
- [ ] Aucun plan ne dure plus de 60 secondes
- [ ] Face cam a chaque changement d'etape
- [ ] Face cam a chaque moment "wow" (reaction)
- [ ] Teaser cut 1-2s du resultat de l'etape suivante avant chaque transition

---

## 4. Post-production

### Sons et musique
- [ ] Nappe musicale calme pour l'intro et les explications
- [ ] Montee en tension pour l'etape 3 (les prompts / star step)
- [ ] Musique epique pour le boss et le reveal final
- [ ] Whoosh a chaque changement de plan rapide
- [ ] Ding / pop a chaque apparition de texte overlay
- [ ] Impact sonore sur le delayed reveal (explosions)
- [ ] Rupture sonore toutes les 60s (changement musique ou effet)
- [ ] Son du jeu present mais mixe sous la voix quand on parle

### Assets IA et overlays
- [ ] Texte anime pour les noms d'etapes (Jitter)
- [ ] Lower thirds pour les numeros de prompts ("Prompt 1/10", "Prompt 5/10")
- [ ] Overlay texte pour les features pointees dans la demo
- [ ] Fleches / cercles pour les zooms sur le CLAUDE.md
- [ ] Animation du value stack (checkmarks qui apparaissent)
- [ ] Palette ISAO respectee : cyan #00B2C2, anthracite #2D2D2D, blanc #FFFFFF
- [ ] Tous les textes lisibles sur mobile (taille suffisante)

### Verifications finales
- [ ] Duree contenu : 10-12 min (hors bridge)
- [ ] Duree totale avec bridge : 13-15 min
- [ ] Pas de segment ecran seul de plus de 60 secondes
- [ ] Pas de greeting en debut de video
- [ ] Pas de conclusion formelle ("j'espere que cette video vous a plu")
- [ ] Le bonus (prompt debug) est bien dans les 30 dernieres secondes du contenu
- [ ] La promesse d'intro (prompts en description) est tenue en outro

- [ ] Video programmee mardi ou jeudi 14h-16h
- [ ] Post Skool avec les prompts en bonus exclusif
- [ ] Cross-promo en end screen de la video d'installation Claude Code
