# Plan Short — J'ai codé un jeu en 15 min avec Claude Code (Sky Raptors)

**Format** : Short / Reel vertical 9:16
**Durée cible** : 55-60 secondes
**Objectif** : Montrer le jeu fini en action + révéler que c'est fait en 15 min avec 10 prompts → donner envie de regarder la vidéo longue.

---

## Structure

### Hook visuel (0-3s)
`[ÉCRAN 9:16]` — Gameplay Sky Raptors en action (tirs, explosions, boss)
**Overlay** : "J'AI CODÉ CE JEU EN 15 MIN"

### Hook verbal (3-7s)
`[FACE CAM 9:16]` — "Ce jeu, c'est 15 minutes et zéro ligne de code. Juste 10 prompts dans Claude Code."
**Overlay** : "0 CODE → JEU COMPLET"

### La méthode (7-15s)
`[ÉCRAN 9:16]` — Montrer le CLAUDE.md (scroll rapide) + un prompt envoyé dans Claude Code
**Overlay** : "ÉTAPE 1: Le brief secret"
→ "Tout commence par un fichier que personne ne montre. Le CLAUDE.md. Tu briefes Claude Code AVANT de coder."

### Les résultats (15-40s)
Montage rapide des résultats clés, ~3s chacun :
- Canvas vide → titre "SKY RAPTORS" (3s)
- Avion cyan avec flammes animées (3s)
- Tirs jaunes en rafale (3s)
- Ennemis rouges en sinusoïde (3s)
- EXPLOSION de particules — moment star (4s)
- Fond étoilé parallax (3s)
- Boss avec barre de vie + power-ups (4s)
- Écran menu + sons (3s)
**Overlay par segment** : numéro du prompt ("PROMPT 1", "PROMPT 4", etc.)

### Reveal (40-50s)
`[ÉCRAN 9:16]` — Gameplay complet du jeu fini, toutes features actives
**Overlay** : "10 PROMPTS. 15 MIN. 0 LIGNE DE CODE."
Slow-motion sur l'explosion du boss.

### CTA (50-57s)
`[FACE CAM 9:16]` — "Le tuto complet avec les 10 prompts est sur la chaîne. Commente PROMPTS si tu veux le guide."
**Overlay** : "TUTO COMPLET SUR LA CHAÎNE"

---

## Notes de production
- **Mots** : ~90 mots parlés
- **Coupes** : 16-18 cuts
- **Musique** : Synthwave progressive, drop au moment de l'explosion du boss
- **Rythme** : Coupes sèches calées sur le beat, 3s par résultat
- **L'étape star** (explosion/collisions) a le segment le plus long et le seul slow-motion
