# Plan Short : Un jeu vidéo en 10 min, 0 ligne de code

**Durée cible** : ≤60 secondes
**Angle** : Le choc visuel — timelapse de la création du jeu du vide à jouable

Le short est une **vidéo indépendante**, pas un extrait du format long.

## Hook Visuel (0-2s)
Écran splitté : à gauche Antigravity avec un éditeur vide, à droite le jeu fini qui tourne avec explosions néon et score. Contraste maximal entre "rien" et "jeu complet".

## Hook Verbal (2-5s)
"10 minutes. Zéro ligne de code. Un jeu vidéo complet."

## Contenu (5-45s)
**Type** : Démo flash / Timelapse
- Ouvrir Antigravity, créer le CLAUDE.md en 3 secondes (flash)
- Taper le prompt visuel dans Claude Code
- Timelapse accéléré (x10) de Claude Code qui génère le code
- Coupe : le navigateur s'ouvre, le jeu apparaît
- On joue 5 secondes — c'est réel, ça marche
- Coupe : "Ajoute des power-ups" tapé dans Claude Code dans Antigravity
- Coupe : le jeu a changé — les power-ups sont là
- Texte superposé : "Claude Code dans Antigravity — gratuit"
- Face cam 3s : "Pas dev. Pas designer. Juste un mec avec une idée."

## Chute + CTA (45-60s)
"Si j'arrive à faire ça en 10 minutes, imagine ce que tu pourrais construire pour ton business. Tuto complet sur la chaîne."

[TEXTE SUPERPOSÉ : "TUTO COMPLET → lien en bio"]
