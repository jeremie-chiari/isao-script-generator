# Script Short : Un jeu vidéo en 10 min, 0 ligne de code

**Durée estimée** : ~55s (165 mots)
**Angle** : Choc visuel — timelapse de la création du jeu, du vide au jouable
**Format** : 9:16 vertical (Instagram Reels / YouTube Shorts)

Ce short est une **vidéo indépendante**. Un viewer qui n'a jamais vu la chaîne doit tout comprendre.
