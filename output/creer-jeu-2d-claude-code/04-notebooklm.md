# Créer un jeu 2D en 10 min avec Claude Code

Un jeu vidéo complet, jouable, créé en 10 minutes — sans écrire une seule ligne de code.

[IMAGE : capture d'écran du jeu fini — space shooter néon avec score, ennemis, explosions]

---

## Le problème

Tu as des idées, mais pas les compétences techniques pour les construire. Un développeur freelance coûte 350 à 950€ par jour. Une app sur mesure : 10 000 à 60 000€. Et toi, tu ne sais pas coder.

[IMAGE : illustration — facture de prestataire tech, interface complexe, symbole "interdit" sur du code]

---

## La solution en 3 étapes

De "je ne sais pas coder" à "j'ai un jeu jouable" en 10 minutes, grâce à Claude Code dans Antigravity — un IDE visuel avec l'IA intégrée.

[IMAGE : roadmap visuelle — Étape 1 : Briefer → Étape 2 : Prompt visuel → Étape 3 : Personnaliser]

---

## Étape 1 : Briefer Claude Code

Tu ouvres Antigravity et tu crées un fichier CLAUDE.md — un brief pour l'IA qui décrit ton projet : le type de jeu, le style visuel, les mécaniques. Comme briefer un collègue avant de lui confier un projet.

[IMAGE : capture d'Antigravity avec le fichier CLAUDE.md ouvert — contenu lisible du brief projet]

---

## Étape 2 : Le prompt visuel ⭐

Au lieu de dire ce que tu veux ("fais-moi un jeu"), tu décris ce que tu VOIS à l'écran : les couleurs, les mouvements, les effets. Claude Code génère un résultat visuellement supérieur. C'est la technique qui change tout.

[IMAGE : capture du jeu fonctionnel — gameplay néon avec particules, score, ennemis par vagues]

---

## Étape 3 : Personnaliser

Tu demandes des modifications en français : "Ajoute des power-ups", "Change les couleurs", "Ajoute un boss final". Claude Code modifie le jeu en 30 secondes. Le jeu devient le tien.

[IMAGE : avant/après — le jeu basique vs le jeu personnalisé avec power-ups néon et boss final]

---

## Les 3 points à retenir

1. Le fichier CLAUDE.md donne le contexte à Claude Code — comme briefer un collègue
2. Le prompt visuel (décrire ce qu'on VOIT) produit des résultats très supérieurs au prompt vague
3. La puissance itérative — tu modifies en 30 secondes ce qui prendrait des heures à un dev
