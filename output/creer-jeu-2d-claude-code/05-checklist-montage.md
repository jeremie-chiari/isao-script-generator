# Checklist de Montage : Créer un jeu 2D en 10 min avec Claude Code

## Vérification pré-montage

- [ ] Roadmap visuel (barre de progression) apparaît dans les 30 premières secondes
- [ ] Étapes 2 et 3 floutées au départ, révélées progressivement
- [ ] Compteur d'étapes visible ("1/3", "2/3", "3/3") à chaque transition
- [ ] Aucun plan ne dure plus de 60 secondes
- [ ] Interruption de rythme toutes les 30-45 secondes
- [ ] Transitions d'étapes contiennent une accroche vers l'étape suivante
- [ ] Face cam utilisée à chaque changement d'étape et chaque moment "wow"
- [ ] Résultat final montré avec "révélation différée" (3-5s de micro-tension)
- [ ] Les 60 dernières secondes suivent la structure de boucle de rétention
- [ ] Bonus/astuce donné dans les 30 dernières secondes
- [ ] Écran de fin avec vidéo "Installer Claude Code" apparaît pendant qu'on parle encore

## Techniques de tension utilisées

- [x] Compteur visuel (compteur d'étapes 1/3, 2/3, 3/3)
- [x] Flash anticipation (flash 1s du jeu final avant transition étape 1 → 2)
- [x] Récap cumulatif (récap ✅ après chaque étape)
- [x] Tension non résolue ("deux choses que personne ne montre" — résolu à l'étape 2)
- [x] Révélation différée (3 occurrences : premier lancement jeu, power-ups, boss final)
- [x] Comparaison avant/après (prompt vague vs prompt visuel — résultat visible)

## Variante de roadmap choisie

- [ ] Flou progressif (étapes écrites mais floutées)
- [ ] Cadenas (cadenas qui s'ouvre)
- [x] Barre de progression
- [ ] Checklist animée (check satisfaisant)

> Recommandation : Barre de progression — idéale pour une vidéo courte (7 min) avec 3 étapes. Simple, lisible, ne prend pas trop de place à l'écran.
